Kiosk link
A short link for the kiosk laptop. Your player list goes on the Fair Dinkum website as a scrambled file that only this link can unlock.
  1. Download the kiosk file (below). It holds your current , scrambled.
  2. Upload it to GitHub: open the kiosk folder upload page, drag the file in and click Commit changes. (Or send it to Claude to publish.) It's live a minute or two later.
  3. Set up the kiosk once: Settings › Accounts › Other users › Kiosk › Microsoft Edge › As a digital sign or interactive display, and paste the link above as the web address.
The link never changes. When your player list changes, just repeat steps 1 and 2 (the new file replaces the old one); the kiosk picks it up next time it starts. Keep the link private: anyone with it can read the list.
