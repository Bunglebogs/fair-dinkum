# Kiosk files

Each `.json` file here is a scrambled (AES-GCM encrypted) Fair Dinkum player list for a kiosk.
It can only be read with the matching kiosk link, which holds the key and is never stored here.

To update a kiosk's player list: in Fair Dinkum on your own computer, open **Players & groups › Kiosk link**, click **Download kiosk file**, and upload it here (it replaces the old one).
